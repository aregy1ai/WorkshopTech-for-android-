🧠 أنماط OCR حسب كل دولة

التنسيقات المدعومة

```kotlin
// PlatePattern.kt
enum class PlateFormat {
    NUMBERS_ONLY,           // 123456 (ليبيا قديم، قطر، اليمن)
    LETTERS_THEN_NUMBERS,   // أ ب ج 1234 (مصر)
    LETTER_NUMBER_MIXED,    // 12345 أ 6 (الإمارات)
    NUMBERS_THEN_LETTER,    // 123456 أ (ليبيا حديث)
    NUMBERS_SPACE_NUMBERS,  // 123 456 (الكويت)
    NUMBERS_DASH_NUMBERS,   // 12-34567 (الأردن)
    LETTER_THEN_NUMBERS,    // ب 123456 (لبنان)
    SHORT_NUMBERS_LETTERS,  // 1234 تونس (تونس)
    ALPHANUMERIC_MIXED      // AB 123 (صومال، جيبوتي)
}
```

قاعدة تنقية مخصصة لكل دولة

الدولة تنظيف خاص
ليبيا تحويل أرقام عربية (٠١٢) → لاتينية (012)
مصر استخراج الحروف العربية أولاً ثم الأرقام
السعودية 3 مقاطع: حروف - حروف - أرقام
الإمارات 3 مقاطع: أرقام - حرف - رقم
الكويت فاصل بين مجموعتي الأرقام
المغرب حرف أخير منفصل
تونس كلمة "تونس" في النهاية

أمثلة لأنماط Regex

